# Impeccable Design Context — Repro-in-a-Box

Confirmed design system for all visual surfaces (HTML reports primary; dashboard/docs site later).

## Design Context

### Users
QA engineers, frontend developers, and platform teams reviewing scan evidence in CI, PRs, or local CLI runs. They need to triage fast, trust severity, copy evidence, and share a single self-contained HTML file.

### Brand Personality
**Forensic. Precise. Confident.**

Tagline energy: “Find bugs. Freeze them. Ship them.” — the UI should feel like an evidence lab, not a marketing SaaS dashboard.

### Aesthetic Direction
- **Visual tone:** Instrument / evidence dossier — dense where useful, quiet elsewhere. Paper + ink, not neon glass.
- **Theme:** Light-first (shared reports in PRs/email); optional dark mode for night triage.
- **Brand signal:** Deep teal (not copper, not purple).
- **References:** Playwright HTML reporter (self-contained, actionable), OpenStatus data-table filters (faceted chips + counts), Phantom Report (searchable issue table + row detail), uiverse.io (CSS-only toggles/chips — restraint, not gimmicks).
- **Anti-references:** Purple-on-white gradients, Inter/Roboto stacks, glassmorphism, identical icon+stat card grids, glow accents, “AI dashboard” hero metrics, cream+terracotta editorial clichés.

### Design Principles
1. **Evidence over decoration** — every color, motion, and control aids triage.
2. **Faceted filtering first** — severity/category/search are primary UI, not afterthoughts.
3. **One composition per section** — avoid card soup; use rhythm, rules, and type hierarchy.
4. **Tokens everywhere** — OKLCH semantic tokens; tinted neutrals; no raw `#000`/`#fff`.
5. **Motion with purpose** — expand/collapse, filter feedback, theme switch, row selection only; respect `prefers-reduced-motion`.

### Confirmed Decisions
- Teal signal accent ✓
- Light-first + dark toggle ✓
- Marketing/docs site deferred until report + CI Action are solid ✓
